# Pro100_Voice_rec
# Voice Assisted Command Executor

Runs in Background as a GUI and uses your microphone to
use commands to allow you to use your computer easier. 
Commands should be persistent.
Utilizes text-to-speech to notify the user when a command is run.

Using VOSK model for voice recognition.

Supports both Windows and Linux.



Starting Commands:

    exit - exits this programm
    steam - opens steam if installed
    open browser - opens your default browser
    turn down volume - lowers your pc volume
    turn up volume - raises your pc volume
    add command - allows you to add custom commands
    mute volume - mutes your pc volume
    unmute volume - unmutes your pc volume
    max volume - puts your pc volume at max value
    min volume - puts your pc volume at min value
    mute mic - mutes your microphone
    unmute mic - unmutes your microphone
    minimum brightness - puts your pc brightness at minimum value
    max brightness - puts your pc brightness at maximum value
    decrease brightness - lowers your pc brightness value
    increase brightness - raises your pc brightness value
    close window - closes the active window
    any custom commands you add using add command
